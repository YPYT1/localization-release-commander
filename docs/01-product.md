# 产品定义

## 一句话

Localization Release Commander 是内容团队的“交付负责人 Agent”：读取平台规范、资产和版权约束，发现阻断项，执行低风险修复，组织人工审批，提交发布并回收 QC 结果。

## 用户与付费方

| 角色 | 目标 | 关键痛点 |
|---|---|---|
| 内容运营 | 按时上线 | 平台规则不同、交付包易漏项 |
| 本地化制作人 | 保证字幕/配音质量 | 时间轴、CPS、版本不一致 |
| 版权/法务 | 控制地区和期限 | 权利信息散落在合同和邮件 |
| 平台交付负责人 | 降低拒片率 | 拒片后难定位责任 |
| 部门负责人 | 看交付效率 | 人工 QC 时间不可量化 |

## 核心场景

“第 8 集准备发布到美国和巴西”：系统发现字幕超速、葡萄牙语时间轴重叠、阿拉伯字体缺失、配音时长偏差、地区版权即将到期、平台格式不匹配；系统自动修复可逆问题，对版权和发布动作请求审批，生成交付包并跟踪平台结果。

## 产品原则

1. 资产是事实，模型只解释事实，不替代事实校验。
2. 低风险、可逆动作自动执行；不可逆或高金额动作必须审批。
3. 每个结论都有来源、版本、时间和责任人。
4. 失败可重试、可恢复、可回滚，不能重复发信或重复发布。

## 成功指标

- 首次平台 QC 通过率 ≥ 90%
- 每集人工 QC 时间下降 ≥ 50%
- 交付阻断项识别召回率 ≥ 95%
- 自动修复回归失败率 ≤ 2%
- 版权期限漏检数 = 0
