# 范围与验收

## MVP 范围

- 内容：中文短剧，单集 5–30 分钟
- 语言：英语、日语、西班牙语
- 平台：YouTube + 一个 OTT 适配器
- 资产：视频、SRT、TTML、配音音频、海报、标题/简介/标签、版权记录
- 异常：字幕 CPS 超限、时间轴重叠、缺字形、配音时长偏差、格式不匹配、版权即将到期

## 不在 MVP

自动翻译、自动配音、全平台发布、自动改法律文案、自动续版权、复杂 DAM/ERP 集成。

## 验收场景

| 编号 | 输入 | 期望结果 |
|---|---|---|
| A1 | 合法视频 + 合法 SRT | 生成交付包并进入待发布 |
| A2 | CPS 超限 18 条 | 自动修复并保留原始版本 |
| A3 | 字幕时间轴重叠 | 阻断并创建人工任务 |
| A4 | 版权 72 小时内到期 | 阻断目标地区发布并要求审批 |
| A5 | 平台要求 TTML、输入为 SRT | 生成 TTML，校验后入包 |
| A6 | 发布接口超时 | 从断点重试，不重复提交 |
| A7 | 人工拒绝修复 | 保持阻断，记录理由和责任人 |

## Definition of Done

每个场景都有固定输入、可复现运行、审计时间线、期望状态和自动化断言；文档中的 API、状态和事件名称与实现保持一致。
