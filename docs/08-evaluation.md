# 评测与验收计划

## 数据集

建立 100 个脱敏交付包：40 个正常、20 个字幕问题、15 个格式问题、15 个版权问题、10 个平台回执失败。每条样本包含期望状态、阻断原因、允许的自动动作和必须审批的动作。

## 指标

| 指标 | 计算 | MVP 门槛 |
|---|---|---|
| Finding 召回率 | 命中的真实问题 / 全部真实问题 | ≥95% |
| 错误阻断率 | 错误阻断 / 全部样本 | ≤5% |
| 自动修复成功率 | 通过回归的修复 / 自动修复数 | ≥98% |
| 重试幂等率 | 重试后重复外部动作 | 0 |
| 审计完整率 | 有来源和责任人的动作 / 全部动作 | 100% |
| 首次 QC 通过率 | 首次通过的交付包 / 全部提交 | ≥90% |

## 测试层级

1. 单元：时间码、CPS、编码、版权窗口、幂等键。
2. 契约：工具 schema、平台 adapter、Webhook/outbox。
3. 图回放：固定 checkpoint 重放，断言状态和动作序列。
4. 沙箱 E2E：真实 ffprobe、对象存储模拟器、平台 sandbox。
5. 人工验收：审批、拒绝、过期、回滚和审计时间线。

## 评测原则

模型质量和工作流质量分开记分；模型“解释得像”不能抵消确定性校验失败。每次 prompt、模型、RuleSet 变更都记录版本并重跑回放集。
