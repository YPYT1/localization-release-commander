# 前端体验与页面规格

## 产品形态

前端分为两个连续表面：

1. **产品介绍官网**：让内容运营、制作人和负责人理解价值并进入试用。
2. **交付工作台**：让真实用户上传资产、处理问题、审批动作、追踪发布。

不把官网做成泛 SaaS 卡片墙，也不把工作台做成营销首页。

## 视觉 thesis

“深色编辑室 + 纸张般的交付清单”：黑曜石底色、暖白文字、单一琥珀色动作色，配合真实的字幕时间轴/片段画面作为视觉锚点；强调可靠、克制和内容行业质感。

## 官网信息架构

| 路由 | 目的 | 主 CTA |
|---|---|---|
| `/` | 解释产品和结果 | 查看一次交付演示 |
| `/workflow` | 讲清从成片到发布的流程 | 试跑样例 |
| `/quality` | 展示字幕、音频、版权 QC | 查看 QC 清单 |
| `/security` | 解释权限、审批和审计 | 查看安全设计 |
| `/demo` | 上传样例并生成报告 | 创建试运行 |
| `/login` | 登录工作台 | 进入工作台 |

### 官网首屏

- 品牌：Localization Release Commander
- 标题：`从成片，到可发布。`
- 副标题：`把字幕、配音、版权和平台规则，收束成一条可审计的交付流程。`
- 主 CTA：`查看一次交付演示`
- 次 CTA：`阅读生产设计`
- 视觉：全宽时间轴与交付包 manifest 的动态组合，不放浮夸的 3D AI 脑图。

### 官网内容顺序

1. Hero：一句承诺 + 交付包实时状态
2. Proof：一个“被阻断的第 8 集”案例
3. Workflow：发现 → 修复 → 审批 → 提交 → 回收 QC
4. Detail：字幕、版权、平台规则的可追溯证据
5. Final CTA：上传样例或进入工作台

## 工作台信息架构

| 路由 | 内容 |
|---|---|
| `/app` | 今日阻断项、待审批、进行中的发布、最近交付 |
| `/app/releases` | 按项目、集数/Release ID、状态、地区和平台筛选的 Release 列表 |
| `/app/releases/new` | 创建 Release、上传资产、选择 RuleSet |
| `/app/releases/:id` | 交付详情、状态、资产、Finding、动作、时间线 |
| `/app/releases/:id/findings` | 问题列表、严重度、来源、修复/指派 |
| `/app/releases/:id/approvals` | 待审批动作、风险解释、批准/拒绝 |
| `/app/rulesets` | 平台规则版本、变更记录、试运行 |
| `/app/audit` | 按 actor、run、时间、动作类型检索审计 |
| `/app/settings` | 成员、角色、平台连接、保留策略 |

## 工作台布局

- 左侧：项目与主导航。
- 中央：当前工作区，优先表格、时间线、检查结果，不默认使用卡片堆叠。
- 右侧 Inspector：选中 Finding/Action/Asset 时显示来源、版本、影响和下一步。
- 顶部：当前项目、环境、运行状态和全局搜索。

## 关键交互

1. **Run 交付检查**：点击后显示阶段进度；每阶段可展开输入、输出和耗时。
2. **Finding 处理**：支持接受建议、重跑检查、指派、忽略并填写理由。
3. **审批**：显示风险级别、影响地区、资产 diff、平台动作和回滚条件；批准/拒绝必须填写确认。
4. **时间线回放**：按事件查看模型、工具、规则、人工决定和外部回执。
5. **版本对比**：字幕/manifest/元数据显示 before/after；原始资产永远可恢复。

## 状态与错误

- 空态：提供一个可下载的样例交付包和“试跑样例”入口。
- 加载态：显示当前阶段和预计剩余步骤，不显示虚假的百分比。
- 阻断态：明确 `BLOCKED` 原因、责任角色和最短解决路径。
- 外部失败：显示 provider request id、是否可重试、重试倒计时和人工替代动作。
- 权限不足：说明所需角色，不泄露平台凭证或隐藏字段。

## 动效与可访问性

- 首屏：时间轴和状态标签做一次克制的进入动画。
- 工作台：状态变化使用共享布局过渡；审批抽屉用短距离滑入。
- 所有动效支持 `prefers-reduced-motion`；键盘可完成筛选、审批和时间线浏览；颜色之外同时使用文字/图标表达状态。

## 前端数据边界

Next.js 只消费 NestJS DTO；不直接读数据库、不执行 ffprobe、不持有平台 token。列表接口支持 cursor 分页和 `updatedAt` 增量刷新。
