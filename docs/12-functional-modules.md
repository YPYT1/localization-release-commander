# 功能模块与交互规格

## 1. 项目与 Release

用户创建项目后，以“集 × 地区 × 平台”为单位创建 Release。创建时必须选择目标语言、RuleSet 版本和交付截止时间。

验收：缺少视频、目标语言或 RuleSet 时不能启动检查；创建成功后写入 `release.created`。

## 2. 资产中心

支持拖拽上传和 manifest 导入；展示 sha256、来源、父版本、语言、时长、编码和关联 Release。上传完成后异步生成媒体元数据。

验收：同一 sha256 不重复存储；修复资产显示父子关系；原始资产不可编辑。

## 3. QC 检查

支持一键运行全部检查，也支持单独重跑字幕、音频、格式、版权和平台规则。每个 Finding 包含 code、severity、source、evidence、suggestedAction 和 status。

验收：规则失败可定位到资产和时间码；规则版本显示在结果中；同一输入重复运行得到相同 Finding。

## 4. 修复中心

Agent 可以提出修复计划，用户查看 diff 后执行。自动修复只生成新资产，不覆盖旧资产。修复后必须自动回归 QC。

验收：修复计划没有结构化输入时不能执行；回归失败自动恢复到修复前 manifest；所有动作有幂等键。

## 5. 版权与地区

用户维护作品、音乐、演员和素材的地区/时间权利。系统在目标发布日期计算权利状态：`VALID`、`EXPIRING_SOON`、`EXPIRED`、`NOT_STARTED`、`UNKNOWN`。

验收：`EXPIRED`/`NOT_STARTED` 阻断发布；`EXPIRING_SOON` 创建 R3 审批；`UNKNOWN` 不得被模型默认为有效。

## 6. 审批中心

按 R0–R3 风险等级路由角色。审批人看到动作 diff、证据、影响和回滚条件；拒绝必须填写理由。

验收：未审批的 R2/R3 不能调用 `submit_delivery`；审批过期后动作失效；审批决定不可编辑。

## 7. 平台交付

由 adapter 将标准 DeliveryCommand 转换为平台请求；保存外部 request id 和原始回执摘要。支持手动重试和 webhook/poll 两种回收方式。

验收：超时不产生重复提交；平台 QC 失败自动回到 `REMEDIATING`；平台不支持回滚时界面明确显示人工补救路径。

## 8. Agent 控制台

展示当前 run 的图节点、工具调用、模型解释、等待中的审批和下一步候选动作。用户可以暂停运行、重试单节点或从 checkpoint 恢复。

验收：每个节点显示输入/输出摘要、版本和耗时；暂停不丢状态；恢复不重复已完成副作用动作。

## 9. 审计与报表

支持按项目、Release、操作者、动作、平台和时间检索；输出交付报告、阻断原因、节省人工时间和平台通过率。

验收：审计记录只追加不可修改；导出报告包含资产哈希、RuleSet、模型/图版本和审批记录。

## 10. 设置与连接

配置成员角色、项目权限、平台连接、通知渠道、文件保留策略和 RuleSet 发布。平台连接使用服务端密钥引用，前端只展示连接状态和末四位标识。

验收：连接测试不暴露密钥；删除连接前显示受影响的 Release；RuleSet 发布需要审批并保留旧版本。
